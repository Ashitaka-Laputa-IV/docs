### 连接到你的 agent

Agent Chat UI 既能连接到[本地 agent](/oss/langgraph/studio#set-up-local-agent-server), 也能连接到[已部署的 agent](/oss/langgraph/deploy)。

启动 Agent Chat UI 之后, 你需要对它进行配置, 让它连接到你的 agent:

1. **Graph ID**: 输入你的 graph 名称 (可在 `langgraph.json` 文件的 `graphs` 下找到)
2. **Deployment URL**: 你的 Agent server 端点 (例如本地开发用 `http://localhost:2024`, 或者你已部署 agent 的 URL)
3. **LangSmith API key (optional)**: 添加你的 LangSmith API key (如果你使用的是本地 Agent server, 则无需填写)

配置完成后, Agent Chat UI 会自动拉取并显示你的 agent 中所有被中断的 thread。

<Tip>
  Agent Chat UI 开箱即支持渲染 tool call 与 tool 结果消息。要自定义显示哪些消息, 请参阅 [在聊天中隐藏消息](https://github.com/langchain-ai/agent-chat-ui?tab=readme-ov-file#hiding-messages-in-the-chat)。
</Tip>
